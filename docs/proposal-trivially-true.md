# 只留平凡为真——v2.9.42 审查 15 发现的本质减法（内核修改建议）

> 状态：**建议（待评审）** · 2026-11-22 · 源头：提交 `01d76b8`（v2.9.42）代码审查 15 条确认发现
> 本文回答三件事：①两轮共 30 条发现为什么同根；②四个机制各自退到「平凡为真」的形态；③哪些取舍是明知的。
> 本文 §3.1 取代 `proposal-defense-subtraction.md` §3.1（其余各节成立，GatewayCtxReject 删除已验证干净）。

## 1. 诊断：凡需证明的断言，都是未来的发现

v2.9.41（拒绝式防线）15 条发现，v2.9.42（批注式）又 15 条。两轮不是手气差，
是同一个根子：**机制里藏着它必须先证明才能陈述的断言**，证明机器本身又生新伤：

| 机制陈述的断言 | 为证明它引入的机器 | 它生出的伤 |
|---|---|---|
| 「已连续执行 N 次**且结果相同**」 | result digest、status 门、截断豁免、`fn+"\x00"` 指纹、json 规范化 | #1 None 崩会话、#2 对未执行说已执行、#5 截断后 digest、#10 撑破 1MB、#12 注释写反、#13 死守卫 |
| 「数据面文件**全部** 0600，一处生效」 | 在 cli 某函数设 umask | #3 token/mail 绕过、#4 stall_watch 裸奔、#15 死 chmod |
| 「**构建期**预热缓存」 | ENV PYTHONDONTWRITEBYTECODE+UV_COMPILE_BYTECODE | #8 ENV 排在烘焙 RUN 之后不生效、#9 内核源码与裸机漏盖 |
| 「发布者只有 daemon 单线程」 | （注释断言，从未为真） | #7 不变量仍是假的、#14 repeat 事件无界 args 灌入 |

对照宪法「递、守门、记账」：机器该**递**的是一个机械事实（次数），不是
一个需要语义验证的判断（结果相同、该不该继续）——后者归大脑，而且它
看着自己的上下文，比任何 digest 都有资格说这句话。

**平凡为真测试**：这个机制陈述的事实，需要机器先证明吗？需要 → 砍掉断言，
只留不需要证明的部分。计数不需要证明（调了就是调了），比较结果需要。

## 2. 修法逐条

### 2.1 批注：15 行 → 4 行，只说「第 N 次调用」（agent.py）

现实现（472-486）的 digest / status 隐忧 / 截断后追加 / `\x00` 指纹 / 规范化
分支 / 事件带 args 全部删除，替换为：

```python
# 收集循环内、content_str 定稿处（序列化后、截断前）：
sig = (fn, tc.get("arguments"))  # 元组 == 比较：None/dict/str 永不抛，无需规范化
_cmd_repeat = _cmd_repeat + 1 if sig == _last_sig else 1
_last_sig = sig
if _cmd_repeat >= 3:
    content_str = (f"[机器批注] 同一命令连续第 {_cmd_repeat} 次调用。"
                   "若在等待外部数据，请 end_session 预约唤醒。\n") + content_str
    log({"event": "tool_repeat_note", "tool": str(fn), "n": _cmd_repeat, "at": iso()})
```

四个形态决策，每个都消一类伤：

- **「调用」不「执行」，不说「结果相同」**——未知工具被调 3 次说「连续第
  3 次调用」仍是真话（#2 消解），于是 status 门、result digest、截断位置
  之争（#5 #10）整体不需要。判断结果是否相同、该不该继续，还给大脑。
- **指纹 = 元组 `==`**——None 名不再崩（#1 消解，无需 str() 补丁），
  isinstance/json.dumps/死守卫全删（#13 消解）。dict 键序敏感的最坏后果是
  **漏计**（连续被判不连续）——漏计是安全方向，多报才是罪。
- **批注作前缀、在截断前拼接**——1MB 口径绝对成立（截断砍尾不砍头，批注
  永远存活，#10 消解）。
- **事件只带 n，不带 args**——同轮 tool_exec 已落 args（#14 消解）。

注释一并改正两处写反/写错的散文（#12：重置语义；proposal 文档 #11：「第
2、3 个」→「第 3 次起每次」，与 `>=3` 对齐）。

### 2.2 权限：进程入口恰好两个，各一行（cli.py、stall_watch.py）

「找一处设 umask」失败两轮，因为前提错了：进程入口不止一个。但全仓数一遍，
**恰好两个且稳定可枚举**：

1. `cli.main()`——run/serve/token/mail 全部经它。`os.umask(0o077)` 从
   `_preflight`（65 行，只盖 run/serve）提到 **main() 顶部**（init_config
   之前）：文件 0600、骨架目录 0700、facts.db、webui_tokens.json 一次全盖
   （#3 消解）。`_preflight` 里的死 chmod（69 行）删（#15）。
2. `stall_watch.py` 首行 `os.umask(0o077)`——壳直接拉起的独立进程，永远
   等不到任何 Python 入口，自己持有基线（#4 消解）。

解耦的检验「换掉它其余不动」现在成立：保护随**进程族**生效，不依赖每个
写点记得 chmod；新增写者零负担，新增第三个进程入口是罕见事件（入口清单
写进 cli.py 注释）。

### 2.3 字节码：一行移动 + 一个 flag，然后明示接受残余（Dockerfile、xuseek.sh）

- `UV_COMPILE_BYTECODE=1` 上移到第一个 uv RUN（61 行）**之前**——Docker
  ENV 不溯及既往，现位置对烘焙层为假（#8 消解）；
- `xuseek.sh pkg_install` 的 uv 调用加 `--compile-bytecode`（55 行）——
  裸机同效（#9 前半消解）；
- 内核源码每次子进程 ~40-70ms 重编译：**接受**，写进 Dockerfile 注释当明知
  取舍。为 50ms 给源码树加 compileall 是收益递减的起点，不做（#9 后半以
  取舍关闭）。

### 2.4 events.py：把注释改真，不发明锁（#7）

`llm_tools.py:28` 从工具 worker 线程 publish 是先于本提交存在的事实，
「发布者只有 daemon 单线程」的注释从未为真。改注释一行（「发布者含 worker
线程；行须短，O_APPEND 单写原子」），不加锁、不加队列。repeat 事件不带
args 后（§2.1），新增写入面已收窄。

### 2.5 测试：两钉一断言，不搞六组

机制越简单，需要钉的不变量越少：

1. `name=null` 的 function_call **不崩会话**、落「未知工具」错误槽——
   这个回归连着 ship 了两版（v2.9.41 错误槽、v2.9.42 崩会话），必须钉；
2. 同命令连调 3 次：第 3 次**仍执行**（结果在场）且带批注前缀——机制的
   存在理由；
3. token 落盘 mode==0o600——权限唯一敏感文件，一行断言进既有 token 测试。

grep 级检查（GatewayCtxReject 零残留）是一时验证，不值得永久测试。

## 3. 取舍（明知的）

1. **机器不再比较结果**。「结果相同」从文案消失；连续计数只凭命令指纹。
   轮询变化资源的大脑不会被打扰（结果变则 sig 变则计数断），真正卡死的
   循环在第 3 次收到一行真话。够不够，由大脑判断——这正是宪法。
2. **漏计可接受**。dict 参数键序漂移会把连续判成断档——批注迟到，不是
   谎报。反方向（规范化）用复杂度换灵敏，不干。
3. **umask 全局最紧（0700/0600）**。管理员要把实例文件分享给同机其他
   用户，自己 chmod——响亮优于静默，与容器现状一致。
4. **内核源码重编译税（~40-70ms/子进程）接受**，理由见 §2.3。
5. **events 多发布者维持现状**。行短、O_APPEND、撕行只丢更新不撕内容，
   只把注释改真；哪天行变长再议。
