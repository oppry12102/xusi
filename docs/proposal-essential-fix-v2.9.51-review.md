## 二、修改设计

### 1. 核心 bug：不修"替换"，删掉字符串手术本身（消 #1、#6）

**病根**：现有代码在「修字符串」（解析失败 → 抠掉 `{}` 再试），
而问题本质是「取首个完整 JSON 对象、忽略尾部冗余」——
标准库 `raw_decode` 就是这个原语。字符串手术既多余又是 bug 源头。

```python
def _loads_args(raw_args: Optional[str]) -> dict:
    """参数解析（单点）。窄容错只修实证形状：kimi 会发尾随冗余 "{}{}"
    （2026-11-10 patrol 四连挂）——改取首个完整 JSON 对象，尾部冗余天然
    被忽略；其它畸形照旧抛，解析归调用方改对重发（不猜格式）。"""
    if not raw_args:
        return {}
    try:
        return json.loads(raw_args)
    except ValueError:
        return json.JSONDecoder().raw_decode(raw_args.lstrip())[0]
```

一次消掉两条发现：

- 引号内 `{}` 由 JSON 解析器自己处理 → 值损坏**不复存在**（#1）
- 无篡改副本 → 报错永远针对真实负载（#6）
- 实证形状 `{}{}` 仍覆盖：首个对象即真参数
- 「不猜格式」纪律保留：不是通用畸形修复器，只是承认"报文尾部可能挂冗余 token"这一 wire 事实

**考虑过的更彻底选项——零容错**（解析失败直接抛，让 LLM 看错重发，
最符合"能让 LLM 做"）：未采纳。kimi 尾巴是**确定性怪癖**而非随机失误，
零容错意味着每次触发都白烧一轮往返；一行解析层兼容是这个事实的诚实最小价。

已证明此路不通。**解耦修法：规则收敛到唯一一处，其余全变指针或删除。**

### 3. seed.py 模板：从"承诺机器行为"改为"授权大脑决策"（消 #2）

v2.9.50 的本质变化就是时效决策权交给了大脑（睡下的 `sleep_seconds`
决定中途行何时被看到）。模板不应再描述机器机制，只需一句契约：

> 睡下之后的新铃才唤醒你；会话中途到达的行，何时处理由你睡下时设的
> sleep_seconds 决定。

即"能让 LLM 做就让 LLM 做"：LLM 拿到决策权与决策所需事实，机器不替它兜底。

### 4. selftest 两处小修（消 #5 + #1 回归防护）

- `_bad_ok = False` 提前初始化（一行）
- 补一条负例：`'{"cmd": "find . -exec cat {} +"}{}'` 的值内 `{}`
  必须原样保留——正是 #1 的回归防护
