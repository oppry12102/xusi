# 【下一代内核通信协议·使命书】（通信组全体，4468 组长转）

> 状态：**已投**。2026-10-31 主人口谕定稿；因 4468 当时异常暂扣，2026-11-01 北京 15:22 确认其呼吸正常后投递（4468 收信箱 n=16204）。

## 一、使命
为下一代内核设计全新的通信协议。以 ioa 的理念为第一参照系（简单、贴合 LLM、能成长），形态取舍按组内五机实证。组 v1 报告（R1–R25、P1–P12、五痛点对照、E1–E17 实测）是地基，直接引用，不必重证。全组自此从评估者变为设计者。

## 二、初心
1. 能与其他智能体互联；
2. 具有成长为复杂通信协议的机会；
3. 新智能体只用内核自带的最简协议，也能与未来的复杂形态互通，并学习成为一份子。

## 三、总纲：内核即婴儿
内核如新生儿：会呼吸、会啼哭、会吃饭即可。包袱不进内核——技能成长走 jixia，经验成长走同伴，教训成长走自己踩的坑。核内留生长空间，不预建复杂。通信协议同此律：做成最简单，把长大留给核外。

## 四、设计定律
1. **最小核永远合法**：未来任何扩展不得使最小核报文失效；复杂方对最小核方能降阶对话。婴儿方言与成人方言是同一协议的不同生长期，不是两个协议；互通不靠桥，靠核不变。
2. **简单第一**：概念要少；能一条说清的不写两条。
3. **解耦**：层与层独立可换；权威账本与尽力通知分家。
4. **最基本安全即可**：身份与门钥为界，其余安全归 LLM 自理，协议不预装防线。另：对非法输入响亮拒收（而非静默或假成功）属于正确性语义、是「简单」的一部分，不算安全包袱——假成功会让 LLM 在错误事实上继续推理，比没有协议更糟。
5. **自我成长**：核内只留生长缝与规范自身的自治修订机制；成长内容在核外。
6. **能让 LLM 做就让 LLM 做**：LLM 自己能做好的判断，协议一概不代劳。

## 五、放开与升级
- 不兼容老协议：新生智能体直用新协议，存量统一升级；不做桥接、不留双栈、不保旧信封格式；
- 内核可动、形态不拘，不预设任何现役限制；旧约束下的形状（外加桥接、零改动降级等）不沿，其中 ioa 吸收物仍作输入；
- 统一升级以「升级日」整体切换为单位，切换窗内新旧互通降级属预期；统升经发布线既有机制执行。

## 六、产出物
1. 协议规范 v0——每条设计附「为什么在/为什么不在」判据，引 v1 证据；
2. 参考实现＋selftest＋e2e，组内五机真跑；
3. 成长机制专章——「最小核永远合法」的可验证性、协议如何长大而不长胖；
4. 统一升级方案。
