新建 xuseek agent
首次启动一次性交割进 workspace/playbook/根智能体.json（此后死键）；address 与 token 都填才生效， token 可写 env:变量名。缺省根（etc/xusi.toml 的 [[default_roots]]）自动预填、可删改； 仅 v2.7.12+ 内核支持——选了旧版内核时创建会报错。
附加配置（可选·高级）
自由 TOML 原样追加进出生 config.toml 末尾（[capabilities] 等内核可选段）；落盘前整体校验，写坏会拒绝创建。
名称 / 使命沿用备份（改参对话框只能改簿记——mission 归 agent 自治，投信让它改）。 备注自动写「从备份克隆于 YYYY-MM-DD」。
📦 备份 agent

把当前 agent 的 data/ + workspace/ + config.toml 打成 tar 包到本地 etc/backups/。 排除：.venv/、xuseek-v2/、__pycache__/、*.pyc、webui_tokens.json。 运行中备份 = SIGSTOP 冻结窗快照（jsonl 为追加型文件，一致性风险低）。
↺ 回滚 agent

从本地 etc/backups/ 选一个备份，原地还原到当前 agent（沿用原 id 与原端口； 内部走 stop → 删旧实例 → 解压备份 → 重启）。要改名 / 换端口克隆新实例请走「新建 agent → 从备份克隆」。
