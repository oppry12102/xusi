或在此粘贴管理面 token：

admin token 用于管理；user token 仅能访问授权范围内的 agent。
token 由管理员在服务器上签发：python -m xusi token new <label> --role user --agents <id>

新建 xuseek agent
默认仅监听 127.0.0.1，外部一律经管理面（端口 ）反代访问；勾选「暴露外网」才会直接对外监听所选端口。
