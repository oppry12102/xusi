名称 / 使命不在此填（沿用备份；改参对话框随时热改）。 备注自动写「从备份克隆于 YYYY-MM-DD」。 流程 = 解压备份 → 从 versions/ 重建该 agent 的 xuseek-v2 私有副本 → 注册到管理面 → 启动。 备份里没有的（.venv/、xuseek-v2/、缓存、token 文件）会按本地现状重建。
📦 备份 agent

把当前 agent 的 data/ + workspace/ + config.toml 打成 tar 包到本地 etc/backups/。 排除：.venv/、xuseek-v2/、__pycache__/、*.pyc、webui_tokens.json。 期间 SIGSTOP 冻结 1–3 秒，对 sleeping agent 几乎无感。
↺ 回滚 agent

从本地 etc/backups/ 选一个备份，原地还原到当前 agent（沿用原 id 与原端口； 内部走 stop → 删旧实例 → 解压备份 → 重启）。要改名 / 换端口克隆新实例请走「新建 agent → 从备份克隆」。
